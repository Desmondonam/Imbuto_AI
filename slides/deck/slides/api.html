API: load once, predict many

app = FastAPI()

model = CropHealthModel(bundle) # once, at startup

 

@app.post("/api/v1/diagnose")

def diagnose(image: UploadFile): # def, not async def

return model.predict(image.file.read())

Now anything can call your model. Interactive docs come free.

Inference is CPU work. With plain def, FastAPI runs it in a thread pool, so the event loop stays free. If you write async def here, one slow prediction blocks every other request. It is a very common mistake. Mention /api/docs, which you will show in the demo.
