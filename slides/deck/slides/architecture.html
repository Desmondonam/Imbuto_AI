Two ideas. First, channels are thin: a new one is an adapter, not a rewrite. Second, heavy work happens before the request: rain summaries are computed in a batch, so a USSD reply never waits for a model. Note we simplified the concept note's Spark, Airflow and Delta stack. Same bronze, silver and gold layers, far smaller engine, because this data is megabytes. Scale when you have the problem.
