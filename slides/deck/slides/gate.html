Walk-forward backtest, 41 seasons, 2006 to 2026 · notebook 4

Slow down here. The code works and the data is real. If we quoted accuracy, it would look great, about 85 percent, because most seasons are not shortfalls. Rule written beforehand: the lower end of the interval must exceed zero. It did not. We also tried other targets, then stopped, because if you keep trying, something will look good by chance. Notice the simple model beat gradient boosting. The hard skill in applied ML is saying no to your own model.
